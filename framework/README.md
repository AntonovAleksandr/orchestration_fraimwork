# Ядро оркестрационного фреймворка

Самостоятельный набор модулей. Ядро не импортирует ничего из проекта: имена ключей задач, защищённые ветки, префиксы
переменных окружения и команды внешних систем задаются профилем. Профиль проекта кладётся в `framework/profiles/<имя>/`.
Подключение профиля опционально: без него ядро работает с нейтральными значениями.

Правило границы: модуль класса «ядро» не содержит проектных токенов. Проверяет тест `framework/tests/test_boundary.py`
по таблице `framework/INVENTORY.md`.

Адаптеры (GitLab, GitHub, трекер задач, Orca, Kubernetes) — отдельные модули. Ядро обращается к ним через интерфейс, а не напрямую.
