# Platform: 1C 8 Enterprise

1C landscape for Gloria Jeans retail operations. This area contains local clones for store and logistics-facing 1C configurations that can affect e-commerce flows through stock, order fulfillment, delivery, and retail-store processes.

## Что здесь лежит

```
1s8-enterprise/
├── 1c-lc/      # logistics / LC 1C configuration
└── 1c-retail/  # retail-store 1C configuration
```

## Когда смотреть сюда

- store-from-store, retail pickup, reserve, shipment, or warehouse-facing hypotheses;
- integration questions where OMS / OTS / Integration behavior depends on 1C retail state;
- branch/history checks for 1C-side delivery, courier, stock, or store-order changes.

## Git

Nested repositories under this directory are not tracked by the workspace root. Keep code changes inside the corresponding nested repo.
