# Platform: Data Analytics

Analytics and data engineering workspace for Gloria Jeans. This area contains Airflow projects, dbt models, and scripts used for analytical pipelines and reporting-adjacent tasks.

## Что здесь лежит

```
data-analytics/
├── airflow-aero/
├── airflow-gj/
├── analytics-scripts/
└── dbt/
```

## Когда смотреть сюда

- analytical pipelines, DAGs, exports, and scheduled data jobs;
- dbt models or warehouse transformations;
- research tasks where business metrics must be traced to their data pipeline source.

## Git

Nested repositories are ignored by the workspace root. Make changes in the relevant child repo only.
