# Platform: ARM / Retail Store Systems

Retail-store workstation and supporting services for Gloria Jeans stores. This platform is adjacent to e-commerce: it participates in store order handling, receiving, stock, labels, POS UI, device integration, and operational tooling.

## Что здесь лежит

```
arm/
├── gloria-jeans-cashier/
├── gloria-jeans-catalog/
├── gloria-jeans-core/
├── gloria-jeans-orders/
├── gloria-jeans-stock/
├── gloria-jeans-pos-ui/
├── gloria-jeans-receiving/
├── gloria-jeans-label-service/
├── gloria-jeans-tsd-ui/
├── gloria-jeans-ui-server/
├── devops/
└── ...other ARM support repos
```

## Когда смотреть сюда

- store execution and ARM-side order lifecycle;
- SFS / retail pickup investigations;
- store stock, receiving, POS UI, label printing, TSD, fiscal or device-related flows;
- retail deployment / ansible / Docker image questions for store software.

## Git

Each child directory is a separate local clone and is ignored by the workspace root. This README is the tracked workspace-level pointer.
