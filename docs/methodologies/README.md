# Methodologies — переиспользуемые методологии

Дом для **методологий, применимых к разным проектам** (research, проектирование, оценка, исполнение).
Каждая методология живёт здесь **один раз** (источник истины), а проекты (`docs/research/*`, `docs/architecture/*`,
планы) **ссылаются** на неё, а не копируют.

## Принцип

- **Канон здесь** — общая методология без привязки к конкретному проекту.
- **В проекте** — тонкий указатель на канон + при необходимости **проектные допущения/дельта** (свои числа, ограничения).
- Не дублировать содержание: правки методологии — здесь; проекты подхватывают автоматически по ссылке.

## Каталог

| Файл | Что внутри | Когда применять |
|---|---|---|
| [`preproject-research.md`](preproject-research.md) | Предпроектное исследование инициативы (доказательное, многосессионное): артефакты проекта, стадии as-is/to-be/gap, evidence-ledger, гипотезы, гардрейлы. Вход для оценки и передачи команде | Когда инициативу нужно разобрать до запуска (3+ систем, многосессионно, as-is/gap, не код) |
| [`initiative-indicative-estimation.md`](initiative-indicative-estimation.md) | Индикативная оценка инициатив на предпроектном исследовании: две оси (инженерный effort vs календарь), три потока (анализ/разработка/тест), класс XXL, критический путь, форма выдачи бизнесу | Когда по итогам предпроекта нужно дать бизнесу индикативный диапазон сроков инициативы |

## Как ссылаться из проекта

В research-проекте (`docs/research/<project>/`) — относительная ссылка:

```markdown
Методика оценки: [`../../methodologies/initiative-indicative-estimation.md`](../../methodologies/initiative-indicative-estimation.md)
```

Опционально завести в проекте локальный файл-указатель (напр. `00-estimation-methodology.md`) с ссылкой на канон
и блоком «проектные допущения», если у проекта свои числа/ограничения.

## Добавление новой методологии

1. Создать `docs/methodologies/<name>.md` — самодостаточно и **project-agnostic**.
2. Добавить строку в таблицу выше.
3. Сослаться из проектов, где она применяется (не копировать содержание).
