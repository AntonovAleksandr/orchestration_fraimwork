Прод-состояние = коммит последней успешной джобы `prod:deploy`, а не голова `master`.

## Что нужно мобильному 3.34.0

Приложение читает `assortment`, `shade*`, `sizeDisplay`, `colorCount`, `groups`, `markable`,
`brand` и `displayType`/`backgroundColor`/`textColor` навигации — это стек beauty и навигации
из release-26.09. `paymentState` (OPSOMN002-284) и документы соответствия (295) приложение 3.34
не читает. Экспресс (46/73/258/270/296/373) уже в проде: BFF `master` = прод с 21.09, ИС
`production` = прод с 21.09.

Без выкатки бэкенда 3.34 не сломается: beauty-поля отсутствуют → рисуется как одежда, полей
навигации нет → обычный список. Но и beauty с новой навигацией в проде не появятся.

## Блокеры

1. **Головы release-26.09 ушли дальше стенда.**
   - catalog-cache `release-26.09` = `edc77632` + 4 коммита OPSOMN002-294 (документы, статус «Новый»).
   - webapi-connector `release-26.09` = `27549593` + 16 коммитов OPSOMN002-289 («В работе»).
   Выкатывать головы нельзя — это непроверенный объём следующего релиза. Выпускать стендовые
   коммиты `edc77632` и `27549593`.
2. **SDK 1.0 в `master`** (`build(deps)!`, Олейников, 25.09) в pim, catalog-cache,
   webapi-connector, cms, customers, baskets, feed. На стенде не был ни в одном из них (стенды
   либо на release-ветках, либо задеплоены до 25.09). Слияние release-26.09 → `master` с
   прод-деплоем из `master` утащит его в прод. Решение за владельцем SDK: либо сначала стенд
   `master` + 26.09, либо выпуск из release-коммитов, а SDK отдельным релизом.
3. **admin-gui-backend `master` закреплён на ветке СНГ:** `composer.lock` тянет клиентов
   `dev-release-opsomn002-232` (задача 232 «Новый»). Прод из `master` = СНГ в проде.
   admin-gui-frontend `master` тоже содержит 232. Для 3.34 админка нужна только ради формы узла
   навигации (52) и групп категорий (15) — решить, выпускать ли её сейчас.
4. **BFF: конфликт `composer.lock`.** `master`: catalog-cache-client `de6db4f2`, pim-client
   `1a291f34`; `release-26.09`: `abc7d1da`, `06d6a599`, cms-client `f54fd143`. При слиянии
   собрать lock заново и проверить, что beauty-геттеры клиента на месте.
