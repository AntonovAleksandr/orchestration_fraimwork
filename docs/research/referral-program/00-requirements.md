## Бизнес-цель

Стимулировать рост объёма заказов через интернет-магазин за счёт реферальной механики «пригласи друга».

---

## Функциональные требования

### FR-01 — Промокод-приглашение в ЛК

- У каждого участника в личном кабинете отображается **уникальный** промокод для приглашения.
- Участвуют клиенты с картой лояльности или зарегистрированным ЛК в ИМ.

### FR-02 — Eligibility приглашённого

- Приглашённый — клиент **без выкупленных заказов в ИМ** (уточнение в тикете: **аналогично APP20** — критерий «одного выкупленного», не «любого заказа»).
- Промокод применяется **1 раз на 1 клиента** (приглашённого).
- Количество приглашённых на одного реферера **не ограничено**.

### FR-03 — Условия промокода (скидка)

- Скидка **20% на все товары**, по аналогии с **APP20**.
- Начисляются **стандартные бонусы ПЛ** за заказ.
- Промокод **только в интернет-магазине** (не в МП).
- **Не суммируется** с другими промокодами.

### FR-04 — Награда пригласившему

- После **выкупа** заказа приглашённого — через **14 календарных дней** — пригласивший получает **500 бонусов**.
- Срок жизни бонусов: **180 дней** (как в действующей ПЛ), списание во всех каналах.

### FR-05 — Отмены и возвраты

| Событие | Поведение |
|---|---|
| **Отмена заказа** приглашённого | Может повторно воспользоваться механикой (как APP20 при Cancelled) |
| **Выкуп + возврат** | Повторное использование **невозможно** |
| **Возврат после выкупа** | Бонусы пригласившему **не списываются** |

### FR-06 — Лимиты реферера

- Ограничений по количеству привлечённых клиентов **нет**.

## Критерии приёмки (верхний уровень, из тикета)

1. Участник с ЛК/КЛ видит свой уникальный реферальный промокод.
2. Приглашённый без выкупов в ИМ применяет промокод 1 раз в чекауте ИМ → −20% + стандартные бонусы.
3. Промокод не работает в МП и не суммируется с другими промокодами.
4. После выкупа заказа приглашённого — через 14 дней пригласившему +500 бонусов.
5. При отмене — повторное использование; при возврате после выкупа — нет.
6. При возврате бонусы пригласившему не списываются.

## Затрагиваемые системы (предварительно)

| Система | Зона ответственности |
|---|---|
| Site (FE) | Блок в ЛК: промокод, копирование/шеринг |
| Integration | Применение в чекауте ИМ; ограничение канала (web-only) |
| ENSI offers | Тип промокода, скидка 20%, правила |
| ENSI customers | Генерация/хранение уникального кода; связь referrer↔referee |
| ENSI baskets | CouponTranslate / GetDiscount (как APP20) |
| OMS | Факт «выкупа» для триггера |
| Сервер скидок (ПЛ) | Отложенное начисление 500 бонусов, TTL 180 дней |
| Mobile App | Явный запрет применения (канал ≠ web) |
