# Реферальная программа ИМ — исследование и проектирование (проект)

**Владелец:** Александр (CTO eCommerce, Gloria Jeans)  
**Источник требований:** Jira [`OPSOMN001-743`](https://jira.gloria-jeans.ru/browse/OPSOMN001-743) «Реферальная программа ИМ: промокод-приглашение и начисление бонусов пригласившему»  
**Старт:** 2026-07-02 · **Статус:** живой проект — Stage 00 завершён, дальше as-is по доменам.

> Цель проекта — дать доказательную базу для **новой реферальной программы интернет-магазина**:
> уникальный промокод в ЛК, скидка 20% приглашённому (по аналогии с APP20), отложенное начисление 500 бонусов
> пригласившему через 14 дней после выкупа. Сначала **as-is** (что уже есть для промо/лояльности), затем **gap + to-be**.
