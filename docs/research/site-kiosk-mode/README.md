## Суть (бриф владельца)

В магазине ставится **большой экран**, показывающий сайт e-com в **режиме киоска**. Железо уже есть — на нём Ubuntu (пилот; не исключён переход на Android + спец-приложение, но это дольше). Нужно **минимально** модифицировать текущий фронт и запуститься в кратчайший срок на 2–3 пилотных магазинах.

Ключевые модификации MVP (из брифа):
- **Стартовая точка — сразу каталог** в корневой категории (root, «все товары»), без главной страницы.
- **Интерфейс — текущий** (как для планшета). Значимой переверстки не требуется.
- **Кнопка «показать товары только этого магазина»** — фильтр по магазинам в листинге **уже фактически есть**; нужно решить, как **привязывать киоск к магазину** (на пилоте — просто).
- **Авто-разлогин**: (а) после создания заказа; (б) по бездействию — попап с обратным отсчётом (30–60 сек, согласовать) → сброс сессии.

Идея расширения (вероятно **не MVP**):
- **Гостевой чекаут** — заказ без логина (ФИО + телефон + адрес как обычно).

Архитектурная гипотеза владельца: это **отдельный инстанс** — как сейчас есть сайт для клиента и сайт для **режима аватара (ASM)** для колл-центра; вероятно появится **`site-kiosk`** со своим доменом и слегка модифицированным фронтом. Но приоритет — запуск за минимальный срок, поэтому на 1-й фазе — минимум модификаций.

## ⚠️ Дизамбигуация (три «режима сайта» — не путать)

| Режим | Кто пользователь | Где живёт | В скоупе? |
|---|---|---|---|
| **Обычный сайт** (клиентский) | Покупатель со своего устройства | `platform/site/gj-ng-front` (apps `site-ru/en/kz`) | базис, от него наследуемся |
| **ASM / аватар** | Оператор колл-центра «от лица клиента» | тот же монорепо, отдельный инстанс/режим (эталон) | 🟡 эталон архитектуры инстанса |
| **Киоск (site-kiosk)** | Покупатель на общем экране в магазине | новый инстанс/режим — **проектируем** | ✅ **это и есть тема** |

Главное отличие киоска от обычного сайта: **общий девайс** (никаких личных данных «между сессиями»), **привязка к магазину**, **жёсткий авто-разлогин**, **старт сразу в каталоге**.

## Скоуп: 6 доменов + синтез

1. **Архитектура инстанса** — отдельный `site-kiosk` (по образцу ASM) vs feature-flag на текущем; домен, окружение, деплой.
2. **Фронт-старт и layout** — старт сразу в каталоге root, скрыть главную, режим планшета/киоска.
3. **Привязка магазина** — фильтр «товары этого магазина» на базе существующего фильтра по складам/магазинам.
4. **Сессия и авто-разлогин** — после заказа + по бездействию (попап-таймер), безопасность общего девайса.
5. **Железо / kiosk-режим** — Ubuntu (chromium kiosk) на пилоте; альтернатива — Android + спец-приложение.
6. **Гостевой чекаут (Phase 2)** — заказ без логина (ФИО+телефон+адрес); влияние на customer-auth/customers/checkout/Integration/OMS.
7. **Синтез** — направление, порядок, **оценка сроков (AI-ускоренная)**, риски, roadmap, открытые вопросы.
