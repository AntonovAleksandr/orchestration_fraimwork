# Маркетплейсы GJ — план исследования

## Метод

Для каждой стадии:

1. Найти требования, регламенты, исследования и задачи в Confluence/Jira.
2. Зафиксировать дату/версию/статус источника.
3. При необходимости точечно сверить утверждение с локальным кодом.
4. Отделить текущий процесс от исторического и планируемого.
5. Записать факты, противоречия, неизвестное и вопросы владельцам.
6. После проверки перенести ключевые строки в `EVIDENCE-LEDGER.md`.

## Уровни уверенности

| Уровень | Значение |
|---|---|
| confirmed | Прямое подтверждение в актуальном первичном источнике |
| high | Несколько независимых согласованных источников |
| proxy | Косвенное подтверждение; источник описывает смежный контур |
| hypothesis | Предположение для последующей проверки |
| unknown | Данных нет, они противоречивы или не удалось получить источник |

- Не раскрывать ключи API, токены, персональные данные и коммерчески чувствительные выгрузки.
- Не выполнять записи во внешние системы.
