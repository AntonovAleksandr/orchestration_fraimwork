h1. Назначение и логика

Метод отдаёт QR-код поставки Wildberries — этикетку, которую наклеивают на паллету и по которой поставку принимают на складе ВБ.

*Основной способ получить QR — ответ метода отгрузки INT.210.0.3.* Он возвращает и номер поставки ВБ, и сам QR, так что в обычном сценарии печать идёт сразу по нажатию кнопки в 1С и этот метод не нужен.

Данный метод — резервный путь для одного случая: поставка отгружена, но этикетка от Wildberries на момент ответа ещё не пришла. Тогда INT.210.0.3 вернёт {{qr_ready: false}} с пояснением, и 1С опрашивает этот метод, пока этикетка не появится.

*Повторно нажимать кнопку отгрузки в этом случае нельзя* — поставка уже отгружена, и повторное нажатие ничего не исправит. Опрос этого метода — правильное действие.

Значение {{supplyID}} — это *наш внутренний номер поставки*, он приходит в поле {{internal_id}} ответа INT.210.0.3. Номер поставки ВБ для этого метода не подходит.

h1. Параметры/тело запроса

Тела нет, параметр передаётся в пути.

|| Поле || Тип || Обяз. || Описание || Пример значения ||
| {{supplyID}} | integer | + | Внутренний номер поставки. Берётся из поля {{internal_id}} ответа INT.210.0.3 | {{57}} |

{code:title=Пример запроса|language=js|collapse=true}
GET /api/v1/station/supply/57/label
{code}

h1. Параметры ответа

|| Поле || Тип || Обяз. || Описание || Пример значения ||
| {{supply_id}} | integer | + | Внутренний номер поставки из запроса | {{57}} |
| {{label_ready}} | boolean | + | Признак готовности этикетки. При {{false}} поля {{label}} в ответе нет | {{true}} |
| {{label}} | string (base64) | - | Этикетка поставки. Данные бинарные, передаются в base64 — перед печатью декодировать | {{JVBERi0xLjQK...}} |

{code:title=Пример ответа — этикетка готова|language=js|collapse=true}
HTTP/1.1 200 OK

{
  "supply_id": 57,
  "label_ready": true,
  "label": "JVBERi0xLjQK..."
}
{code}

{code:title=Пример ответа — этикетка ещё не пришла|language=js|collapse=true}
HTTP/1.1 200 OK

{
  "supply_id": 57,
  "label_ready": false
}
{code}

h1. Описание и обработка ошибок

|| HTTP || Код ошибки || Текст || Действие ||
| 400 | {{invalid_supply}} | supplyID must be a number | В пути передан не номер. Использовать {{internal_id}} из ответа INT.210.0.3 |
| 500 | {{label_failed}} | cannot read the supply label | Повторить запрос; при повторении — в поддержку |

Отдельно про {{label_ready: false}}: это *не ошибка*. Поставка отгружена, состав зафиксирован, ждём только этикетку от Wildberries. Разумный порядок для 1С — опрос раз в 5–10 секунд в течение нескольких минут, дальше сообщение оператору и обращение в поддержку.

h1. Связанные интеграции

INT.210.0.1 — стикер сборочного задания.

INT.210.0.3 — передача списка заказов при отгрузке поставки, основной источник QR-кода.
