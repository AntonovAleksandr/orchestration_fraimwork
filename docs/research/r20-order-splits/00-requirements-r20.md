## Бизнес-требование (роли)

**Пользователь хочет:** добавить N>1 товаров в корзину → перейти в чекаут → авторизоваться → выбрать регион →
увидеть приблизительные сроки/стоимость доставки → выбрать способ (самовывоз / курьер) → при невозможности
привезти весь состав одной посылкой увидеть **сплит по товарам** (напр. A+C, B+E, D), **сроки по комбинации**
и **стоимость доставки** (если не достигнут порог) → выбрать оплату → оформить → видеть в ЛК родительский заказ
и отправления внутри → получать уведомления по каждому отправлению → отменять отправления по отдельности/все →
видеть бонусы за отправления → получать отправления по мере поступления.

**Бизнес-заказчик хочет:** чтобы это работало на сайте и в МП; пересчёт корзины по доступности/ценам при смене
региона; **OMS на этапе чекаута рассчитывает**, что весь состав нельзя собрать с одного склада; OMS считает
**модели факторинга**:
- **SFS** — Ship from Store (доставка в ПВЗ или на адрес)
- **C&R** — Click & Reserve (сборка в магазине)
- **C&C** — Click & Collect (доставка в магазин)
- **Доставка со склада** (в ПВЗ или на адрес)
- **Доставка с 3PL** (в ПВЗ или на адрес)

## Алгоритмы разбивки (из приложения «Решение Starfish»)

**Сортировка доступных складов в пределах ЛГ** по: удалённости · стоимости доставки (по справочнику, не у ТК) ·
товарным остаткам · приоритету склада · весу товара (тяжёлый — предпочтительнее) · (опц.) стоимости позиций ·
(опц.) приоритету по типу склада (сначала магазины) — приоритет задаётся на уровне склада, бизнес-правилом ЛГ.

**Разбивка с учётом полноты корзины:** (1) ищем склады с наибольшей комплектностью → (2) выбираем склад по
правилам сортировки → (3) ищем склады для недоступных позиций → (4) выбираем по правилам → (5) итерация
(вопрос: лимит итераций?) → (6) запрос в ТК сроков/стоимости по выбранным складам.

**Разбивка без учёта полноты корзины:** (1) склады, где есть хоть какие-то позиции → (2) выбор по сортировке →
(3) наиболее приоритетные склады, покрывающие весь заказ → (4) запрос в ТК.

**Параметры-ограничители (на уровне ЛГ):** макс. кол-во разбивок · макс. стоимость логистики ·
мин. стоимость одного отправления · порог мин. стоимости для доставки из одного склада.

**Следующий этап (вне MVP, отметить):** «перемаршрутизация» при обнаружении частичной сборки;
трассировка сработавших правил для бизнеса/тестирования гипотез; подробные инструкции бизнес-пользователям;
масштабирование на другие страны (таможня, консолидация — был в OROB).
