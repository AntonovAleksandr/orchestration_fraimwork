# Stage 02 — OMS: движок факторинга / разбиения

**Статус:** pending · **BP-якорь:** docs/bp/06 · **Требования R-20:** FR-1, FR-5, FR-6, FR-7, FR-8, FR-9, FR-12, FR-13

## 0. Scope и гипотезы
- **Сердце фичи.** Алгоритм выбора складов и разбиения корзины на отправления:
  - триггер: ни один склад ЛГ не даёт полную комплектацию (FR-6);
  - факторы: кол-во доступного товара, расстояние, сумма цен; приоритет факторов из ЛГ (FR-7);
  - приоритезация складов по типу магазин/склад (FR-8);
  - модели факторинга: SFS, C&R, C&C, доставка со склада, 3PL;
  - лимиты/пороги ЛГ: макс. отправлений (FR-5), мин. стоимость сплита (FR-9), мин. стоимость отправления (FR-12);
  - авто-докомплектация «ещё только одно отправление» при частичной сборке (FR-13).
- Разобрать оба алгоритма из приложения R-20 (с/без учёта полноты корзины) — см. `00-requirements-r20.md`.
- **Гипотеза:** есть логистический сток-резолвинг (выбор склада), но многоскладовое разбиение «на отправления»
  с правилами ЛГ и моделями факторинга — частично/нет. Уточнить роль Go-сервиса `logistics`.
