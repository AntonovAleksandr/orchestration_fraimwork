# Stage 09 — Платежи

**Статус:** pending · **BP-якорь:** docs/bp/05 · **Требования R-20:** FR-19, FR-20, FR-21, FR-25

## 0. Scope и гипотезы
- **FR-20:** онлайн-оплата — одним платежом за родительский заказ.
- **FR-21:** оплата при получении — частями, по каждому дочернему отправлению.
- **FR-19:** способ оплаты доступен, только если **все** отправления его поддерживают (пересечение).
- **FR-25:** холдирование/списание отдельно по каждому отправлению, общие правила холдирования.
- ⚠️ Дизамбигуация: «Яндекс.Сплит» (рассрочка) — отдельная фича; отметить пересечение, но не смешивать.
- **Гипотеза:** онлайн-оплата уже единым платежом за заказ; «частичная оплата при получении per shipment»
  и «пересечение доступных способов по отправлениям» + per-shipment холд — новое.
