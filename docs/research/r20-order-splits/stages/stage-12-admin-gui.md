- Настройки бизнес-пользователем **на уровне логистической группы (ЛГ)**:
  макс. кол-во отправлений (FR-5), приоритет факторов разбиения (FR-7), приоритет складов по типу (FR-8),
  мин. стоимость сплит-заказа (FR-9), стоимость доставки сплита (FR-10), порог бесплатной доставки (FR-11),
  мин. стоимость отправления по способу доставки (FR-12).
- Отображение отправлений в админке (FR-14) + трассировка сработавших правил (из приложения R-20).
- **Гипотеза:** настройки ЛГ существуют (склады/доставка), но специфичные параметры сплита и интерфейс
  трассировки правил — отсутствуют. Уточнить, где «живут» ЛГ (OMS Settings / cloud-configs / ENSI admin).
