## 🤝 Когда агент обращается

Каждый агент представляется с:
- 🎭 Роль (Researcher / Analyst / Developer / Reviewer)
- 📍 Фаза (Research / Analysis / Development / Review)
- 🎯 Контекст (что делает сейчас)
- ❓ Вопросы (что нужно уточнить)
- 💬 Как помочь (варианты помощи)

**Что делать:**
1. Прочитать профиль агента в `.claude/orchestration/agent-profiles.md`
2. Понять его роль и контекст
3. Ответить конкретно на его вопросы
4. Сказать "продолжай" чтобы продолжить выполнение
